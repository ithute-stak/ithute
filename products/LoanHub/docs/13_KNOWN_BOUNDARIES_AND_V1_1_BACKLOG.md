# Known Boundaries and Suggested v1.1 Backlog

These are not represented as completed production integrations in v1.0:

- Official live M-Pesa and EcoCash certification, provider callbacks, status enquiry and reversals.
- Automatic email delivery of scheduled reports.
- S3/MinIO object storage for horizontally scaled deployments.
- Enterprise malware/antivirus scanning of uploads.
- Client-to-client end-to-end chat encryption.
- Formal statutory accounting/tax certification.
- Broad automated browser end-to-end tests for every role.

Recommended v1.1 priorities: provider integration, object storage and malware scanning, report email delivery, accounting period locks/bank reconciliation, automated test coverage and observability dashboards.
