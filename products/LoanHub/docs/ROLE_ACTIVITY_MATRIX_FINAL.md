# Role Activity Matrix

| Role | Primary activities | Required daily attention |
|---|---|---|
| Platform owner | Tenant approval, plans, platform accounting, errors, audit, role switching | Pending companies, critical incidents, payment/platform exceptions |
| Company owner | Company-wide governance, branches, staff, subscription, accounting, reports | Portfolio, overdue loans, failed payments, access changes |
| Company administrator | Daily tenant administration and cross-department coordination | Notifications, master data, incomplete workflows |
| Branch manager | Branch staff, branch lending, collections and performance | Branch queue, workload, overdue accounts, exceptions |
| Loan officer | Requests, affordability review, offers and documentation | New/expiring requests and offer outcomes |
| Finance officer | Disbursements, receipts, reconciliation and journals | Pending/failed transactions and unposted evidence |
| Collections officer | Due/overdue follow-up and promise tracking | Overdue queue and payment verification |
| Compliance officer | Consent, role/access, regulatory evidence and remediation | High-risk events and audit exceptions |
| Auditor | Independent operational and financial evidence review | Scoped samples, findings and supporting reports |
| Customer support | Account/navigation support and safe escalation | Unread conversations and unresolved user cases |
| HR manager | Employee records, employment lifecycle and protected files | Hires, transfers, probation and access-offboarding alignment |
| Performance manager | Goals, reviews and fair analytics | Due goals, missing reviews and data-quality issues |
| Risk manager | Credit, concentration, fraud and operational risk | Overdue trend, unusual changes and failed payments |
| IT support | Incident reproduction, root-cause resolution and safe support | Platform-owner-assigned incidents and recurring fingerprints |
| Borrower | Profile, requests, offers, loans, repayments, chat and files | New offers, upcoming instalments and payment status |
