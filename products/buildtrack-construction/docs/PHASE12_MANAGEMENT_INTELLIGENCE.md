# Phase 12 — Management Intelligence

Phase 12 converts already-controlled BuildTrack records into company, branch and project intelligence. It does not create a parallel operational ledger.

- Director dashboard: portfolio revenue, exposure, receivables and forecast margin in Maloti.
- Branch comparison: revenue, commitment exposure, forecast margin and critical-project count.
- Project health: baseline budget, actual costs, approved procurement/subcontract commitments, current revenue, forecast margin, critical risk count and time remaining.
- Tender pipeline: open, awarded, lost, value and 30-day closing information.
- Fleet intelligence: serviceability, fuel litres/cost, maintenance cost and open maintenance workload.
- Materials intelligence: controlled stock value and reorder-level exceptions using existing reserved quantities.
- Exception feed and portfolio CSV export, scoped to each user's authorised company/branch/site permissions.

The dashboard is decision support. It does not alter budgets, approve transactions, issue tenders, buy materials, dispatch vehicles, create accounting entries or override source-module controls.
