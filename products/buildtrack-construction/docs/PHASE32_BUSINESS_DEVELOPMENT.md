# Phase 32 — Business Development & Opportunity Pipeline

Phase 32 records supplied client opportunities before they become controlled Phase 5 tenders. Each `BDO` opportunity is company, branch and optional site scoped.

- Leads retain client, source, value/probability indicators, expected bid date, scope summary and follow-up data.
- An independent reviewer can qualify a lead only when client contact, scope and bid-date evidence have been recorded.
- Staff can add dated follow-up activities. Qualified opportunities can link only to an existing same-branch Tender Management record.
- Closing an opportunity as won/lost requires a supplied close-out note and creates an audit event. It does not create a project or award work.

The probability-weighted pipeline is derived decision support from staff-entered values; it is not a contractual forecast, tender decision, project mobilisation or financial commitment.
